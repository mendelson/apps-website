แอป Garmin Connect IQ โดย M. Mendelson

← กลับไปที่แอป

อัปเดตล่าสุด: 13 กันยายน 2026

นโยบายความเป็นส่วนตัวนี้ใช้กับแอปพลิเคชัน Garmin Connect IQ ทั้งหมดที่เผยแพร่โดย M. Mendelson — ทั้งฟิลด์ข้อมูลและหน้าปัดนาฬิกา รวมถึงแอปที่จะเปิดตัวในอนาคต (“แอป”) นโยบายนี้อธิบายว่าแอปเก็บข้อมูลการใช้งานอะไรบ้าง เพราะเหตุใด และคุณมีทางเลือกอะไรบ้าง

แอปติดตั้งจาก Garmin Connect IQ Store และทำงานบนอุปกรณ์ Garmin ของคุณ การใช้แพลตฟอร์ม Garmin ของคุณยังอยู่ภายใต้นโยบายความเป็นส่วนตัวของ Garmin เอง ซึ่งแยกจากนโยบายนี้

1. ผู้รับผิดชอบ

แอปเหล่านี้พัฒนาและดูแลโดยนักพัฒนาอิสระ M. Mendelson (“นักพัฒนา”, “ผม”) หากมีคำถามหรือคำขอเกี่ยวกับความเป็นส่วนตัว โปรดติดต่อ: mateusmendelson@hotmail.com

2. ข้อมูลที่แอปเก็บ

เพื่อให้เข้าใจว่าแอปถูกใช้งานบนอุปกรณ์ต่าง ๆ อย่างไรและเพื่อปรับปรุงแอป แอปจะส่งบันทึกการใช้งานขนาดเล็กเมื่อทำงาน บันทึกนี้อาจประกอบด้วย:

ข้อมูลแหล่งที่มาวัตถุประสงค์
ปีเกิด (คืออายุโดยประมาณ)โปรไฟล์ผู้ใช้ Garmin ของคุณทำความเข้าใจกลุ่มผู้ใช้และปรับปรุงแอป
เพศโปรไฟล์ผู้ใช้ Garmin ของคุณทำความเข้าใจกลุ่มผู้ใช้และปรับปรุงแอป
รุ่นอุปกรณ์การตั้งค่าอุปกรณ์วินิจฉัยปัญหาเฉพาะอุปกรณ์ และจัดลำดับความสำคัญของการสนับสนุน
ตัวระบุอุปกรณ์ (ตัวระบุเฉพาะต่อการติดตั้งที่ Garmin ให้มา)การตั้งค่าอุปกรณ์นับจำนวนอุปกรณ์ที่แตกต่างกันและตัดบันทึกที่ซ้ำ
ภาษาของระบบการตั้งค่าอุปกรณ์ทำความเข้าใจว่าควรรองรับภาษาใดบ้าง
ส่วนต่างเขตเวลา & เวลาที่ใช้งานนาฬิกาของอุปกรณ์ช่วงเวลาการใช้งานและสถิติ
โปรไฟล์กีฬา/กิจกรรมปัจจุบัน (เช่น วิ่ง ปั่นจักรยาน)โปรไฟล์กิจกรรม Garminทำความเข้าใจว่าแอปถูกใช้งานอย่างไร
กำลังบันทึกกิจกรรมอยู่หรือไม่ และเวอร์ชันของแอปสถานะของแอปการแก้ไขข้อบกพร่องและสถิติเวอร์ชัน

ปีเกิดและเพศอ่านจากโปรไฟล์ที่คุณตั้งค่าไว้ใน Garmin Connect หากคุณไม่ได้ตั้งค่าไว้ แอปจะไม่สามารถใช้ข้อมูลนี้ได้

3. การติดตามสด (Tracker Data Field)

Tracker Data Field มีฟีเจอร์ติดตามสดที่เลือกใช้ได้ เมื่อคุณตั้งค่าด้วย Track ID และบันทึกกิจกรรม ฟิลด์ข้อมูลจะส่งบันทึกแบบสดเกี่ยวกับกิจกรรมนั้นจากนาฬิกาของคุณ — ค่าต่าง ๆ ที่ฟีเจอร์นี้มีไว้เพื่อแชร์ เช่น เวลาที่ผ่านไป เพซ และระยะทาง และตำแหน่งของคุณในกรณีที่ฟีเจอร์ให้ข้อมูลนี้ — ไปยังเซิร์ฟเวอร์ที่นักพัฒนาเป็นผู้ดูแล เพื่อให้หน้าติดตามที่ apps.mmendelson.com/tracker แสดงข้อมูลเหล่านี้แก่ผู้ที่ป้อน Track ID นั้น

การแชร์นี้เป็นแบบเลือกใช้และเริ่มโดยคุณเอง: จะไม่มีการส่งข้อมูลใด ๆ เว้นแต่คุณใช้ฟิลด์ข้อมูลพร้อม Track ID อย่างแข็งขัน และการเริ่มใช้งานถือเป็นการยินยอมให้ส่งข้อมูล ทุกคนที่รู้ Track ID ของคุณจะเห็นบันทึกที่แชร์ได้ ดังนั้นโปรดถือว่าเป็นลิงก์ส่วนตัวและให้เฉพาะคนที่คุณไว้ใจ บันทึกเหล่านี้จะเก็บไว้เพียงเท่าที่จำเป็นต่อการให้บริการฟีเจอร์ คุณหยุดการส่งได้ทุกเมื่อโดยจบกิจกรรมหรือนำฟิลด์ข้อมูลออก และขอให้ลบบันทึกที่จัดเก็บไว้ได้ผ่านที่อยู่ในส่วนติดต่อ

4. ไม่สามารถระบุตัวตนของคุณได้

แอปไม่ขอและไม่เก็บชื่อ ที่อยู่อีเมล หมายเลขโทรศัพท์ หรือข้อมูลการเข้าสู่ระบบบัญชีใด ๆ ของคุณ และข้อมูลข้างต้นไม่ได้เชื่อมโยงกับตัวตนของคุณใน Garmin Connect หรือบัญชีอื่นใด ตัวระบุอุปกรณ์เป็นค่าที่ Garmin ให้มาซึ่งใช้เพียงแยกอุปกรณ์หนึ่งออกจากอีกอุปกรณ์หนึ่ง เพื่อให้นับบันทึกการใช้งานและตัดรายการซ้ำได้ — ไม่ใช่ชื่อของคุณ และไม่ได้ใช้เพื่อหาว่าคุณเป็นใคร ด้วยเหตุนี้ ข้อมูลที่แอปเก็บจึงไม่สามารถระบุตัวคุณว่าเป็นบุคคลที่เจาะจงและมีชื่อได้ด้วยตัวเอง ข้อยกเว้นเดียวคือฟีเจอร์ติดตามสดที่เลือกใช้ได้ซึ่งอธิบายไว้ในส่วนก่อนหน้า: บันทึกที่คุณเลือกแชร์ที่นั่นอาจมีข้อมูลตำแหน่ง และทุกคนที่มี Track ID ของคุณจะเห็นได้ — นั่นคือวัตถุประสงค์ของฟีเจอร์นี้

5. วิธีใช้ข้อมูล

  • เพื่อทำความเข้าใจว่าแอปถูกใช้กับอุปกรณ์ ภาษา และประเภทกิจกรรมใดบ้าง
  • เพื่อแก้ไขข้อบกพร่อง จัดลำดับความสำคัญของการปรับปรุง และจัดทำสถิติการใช้งานแบบรวม

ผมไม่ขายข้อมูลส่วนบุคคลของคุณ และไม่นำไปใช้เพื่อการโฆษณาหรือสร้างโปรไฟล์โฆษณา

6. การเก็บรักษา & ความปลอดภัยของข้อมูล

ข้อมูลการใช้งานส่งผ่านการเชื่อมต่อที่เข้ารหัส (HTTPS) และเก็บไว้เพียงเท่าที่จำเป็นต่อการทำงานของแอปและการจัดทำสถิติ หลังจากนั้นจะถูกลบหรือเก็บไว้ในรูปแบบรวม ไม่มีวิธีการส่งหรือจัดเก็บใดที่ปลอดภัย 100% แต่ผมใช้มาตรการที่สมเหตุสมผลเพื่อปกป้องข้อมูลจำนวนจำกัดที่เก็บรวบรวม

7. ความเป็นส่วนตัวของเด็ก

แอปเป็นเครื่องมือฟิตเนสสำหรับการใช้งานทั่วไปและไม่ได้มุ่งเป้าไปที่เด็ก ผมไม่เก็บข้อมูลส่วนบุคคลจากเด็กที่อายุต่ำกว่าที่กฎหมายท้องถิ่นกำหนดโดยเจตนา หากคุณเชื่อว่ามีเด็กให้ข้อมูลดังกล่าว โปรดติดต่อผมแล้วผมจะลบข้อมูลนั้น

8. สิทธิ & ทางเลือกของคุณ

  • ข้อมูลอายุและเพศมาจากโปรไฟล์ Garmin ของคุณ คุณแก้ไขหรือล้างช่องเหล่านี้ใน Garmin Connect ได้ทุกเมื่อ
  • คุณถอนการติดตั้งแอปได้ทุกเมื่อเพื่อหยุดการทำงานและการส่งข้อมูลการใช้งานใด ๆ การติดตามสดจะส่งข้อมูลเฉพาะขณะที่คุณใช้ Tracker Data Field พร้อม Track ID อย่างแข็งขันเท่านั้น
  • ขึ้นอยู่กับถิ่นที่อยู่ของคุณ คุณอาจมีสิทธิสอบถาม — โดยไม่เสียค่าใช้จ่าย — ว่ามีข้อมูลใดเชื่อมโยงกับอุปกรณ์ของคุณ และขอเข้าถึง แก้ไข หรือขอให้ลบข้อมูลนั้น เมื่อได้รับคำขอ ผมจะลบทุกอย่างที่เชื่อมโยงกับอุปกรณ์หรือ Track ID ของคุณและหยุดการประมวลผลเพิ่มเติมทั้งหมด ส่งอีเมลถึงผมตามที่อยู่ด้านล่าง

9. การเปลี่ยนแปลงนโยบายนี้

ผมอาจปรับปรุงนโยบายความเป็นส่วนตัวนี้เป็นครั้งคราว วันที่ “อัปเดตล่าสุด” ที่ด้านบนแสดงถึงเวอร์ชันล่าสุด การเปลี่ยนแปลงที่สำคัญจะแสดงไว้ในหน้านี้
