隐私政策

M. Mendelson 的 Garmin Connect IQ 应用

← 返回应用

最后更新：2026年9月13日

本隐私政策适用于 M. Mendelson 发布的所有 Garmin Connect IQ 应用——包括数据字段和表盘，也包括今后发布的任何应用（以下简称"本应用"）。它说明本应用收集哪些使用信息、为何收集，以及你可以做出的选择。

本应用从 Garmin Connect IQ 商店安装，并在你的 Garmin 设备上运行。你对 Garmin 平台的使用还受 Garmin 自己的隐私政策 约束，它独立于本政策。

1. 谁是负责人

本应用由独立开发者 M. Mendelson（以下简称"开发者""我"）开发和维护。如有任何隐私问题或请求，请联系：mateusmendelson@hotmail.com。

2. 本应用收集的信息

为了了解本应用在不同设备上的使用情况并加以改进，本应用在运行时会发送一条简短的使用记录。该记录可能包括：

数据来源用途
出生年份（即大致年龄）你的 Garmin 用户资料了解用户群体并改进本应用
性别你的 Garmin 用户资料了解用户群体并改进本应用
设备型号设备设置诊断特定设备的问题，确定支持优先级
设备标识符（由 Garmin 提供、每次安装唯一的标识符）设备设置统计不同设备数量并去除重复记录
系统语言设备设置了解需要支持哪些语言
时区偏移 & 使用时间设备时钟使用时间分布与统计
当前运动/活动配置（例如跑步、骑行）Garmin 活动配置了解本应用的使用方式
是否正在记录活动，以及本应用的版本应用状态调试和版本统计

出生年份和性别读取自你在 Garmin Connect 中设置的个人资料。如果你没有设置，本应用就无法获取这些信息。

3. 实时追踪（Tracker Data Field）

Tracker Data Field 包含一项可选的实时追踪功能。当你使用 Track ID 进行设置并记录活动时，该数据字段会从你的手表向开发者运营的服务器发送该活动的实时记录——即这项功能用于分享的数值，例如已用时间、配速和距离，以及在功能提供的情况下你的位置——以便 apps.mmendelson.com/tracker 上的追踪页面可以向输入该 Track ID 的任何人显示这些记录。

这种分享是可选的，并由你主动发起：除非你主动使用设置了 Track ID 的数据字段，否则不会传输任何内容，而开始使用即表示你同意传输。任何知道你的 Track ID 的人都可以查看分享的记录，因此请把它当作私密链接，只告诉你信任的人。这些记录只在提供该功能所需的时间内保存；你可以随时通过结束活动或移除数据字段来停止传输，也可以通过"联系"部分中的地址要求删除已保存的记录。

4. 无法识别你的个人身份

本应用不会要求或收集你的姓名、电子邮件地址、电话号码或任何账号登录信息，上述信息也不会与你在 Garmin Connect 或任何其他账号中的身份相关联。设备标识符是 Garmin 提供的一个值，仅用于区分不同设备，以便统计使用记录并去除重复——它不是你的姓名，也不会被用来查明你是谁。因此，本应用收集的信息本身无法将你识别为某个具体的、有名有姓的人。唯一的例外是上一部分所述的可选实时追踪功能：你主动选择在其中分享的记录可能包含位置数据，任何拥有你的 Track ID 的人都能看到——这正是该功能的用途。

5. 信息的使用方式

  • 了解本应用在哪些设备、语言和活动类型中使用。
  • 修复错误、确定改进的优先级，并生成汇总的使用统计。

我不会出售你的个人信息，也不会将其用于广告或建立广告画像。

6. 数据保留 & 安全

使用信息通过加密（HTTPS）连接传输，仅在运行本应用和生成统计所需的时间内保留，之后将被删除或以汇总形式保存。没有任何传输或存储方式是 100% 安全的，但我会采取合理措施保护所收集的有限信息。

7. 儿童隐私

本应用是通用的健身工具，并非面向儿童。我不会在知情的情况下收集未达到当地法律规定年龄的儿童的个人信息。如果你认为有儿童提供了此类信息，请联系我，我会将其删除。

8. 你的权利 & 选择

  • 年龄和性别数据来自你的 Garmin 个人资料；你可以随时在 Garmin Connect 中编辑或清除这些字段。
  • 你可以随时卸载本应用，使其停止运行并停止发送任何使用信息；实时追踪只会在你主动使用设置了 Track ID 的 Tracker Data Field 时进行传输。
  • 视你所在地区而定，你可能有权免费询问与你的设备相关联的信息，并访问、更正或要求删除这些信息。应你的要求，我会删除与你的设备或 Track ID 相关的所有信息，并停止任何进一步处理。请发送电子邮件至下方地址。

9. 本政策的变更

我可能会不时更新本隐私政策。页面顶部的"最后更新"日期反映最新版本。重大变更将在本页面上体现。

网站分析与 Cookie

本网站属于 mmendelson.com 网站家族（mmendelson.com、apps.mmendelson.com 和 run.mmendelson.com），三个网站共享同一个 Google Analytics 统计，因此在它们之间往来的一次访问会被视为一段旅程，而不是三次互不相关的访问。Google Analytics 记录汇总的使用情况：页面浏览、点击及类似事件，以及 Google 从请求中推断出的国家、地区、城市、语言、浏览器、操作系统和设备类型。分析存储（Cookie）默认关闭，只有在你通过 Cookie 横幅同意后才会开启。同意后还会开启 Google 信号，对于登录了已开启广告个性化功能的 Google 账号的访客，加入 Google 自己对年龄段、性别和兴趣的估算——这些是 Google 做出的估算，绝不是你告诉本网站的任何信息；它们只以汇总形式呈现，而且当人数太少无法保持匿名时，Google 会完全隐去这些数据。如果拒绝，分析将在不使用 Cookie 的情况下进行：只有汇总计数，没有人口统计信息，也没有 Cookie。你可以随时通过三个网站任一网站页脚的"Cookies"链接更改你的选择。网站分析不会收集任何可识别个人身份的信息，并且与上文所述的 Garmin 应用数据相互独立。
