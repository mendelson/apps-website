M. Mendelson の Garmin Connect IQ アプリ

← アプリ一覧に戻る

最終更新日：2026年10月2日

このプライバシーポリシーは、M. Mendelson が公開するすべての Garmin Connect IQ アプリケーションに適用されます。データフィールドもウォッチフェイスも、今後リリースされるアプリも含みます（以下「本アプリ」）。本アプリがどのような利用情報を収集するのか、その理由、そしてあなたが選べることを説明します。

本アプリは Garmin Connect IQ ストアからインストールされ、お使いの Garmin デバイス上で動作します。Garmin プラットフォームのご利用には、本ポリシーとは別に Garmin 自身のプライバシーポリシー も適用されます。

1. 責任者

本アプリは、独立した開発者である M. Mendelson（以下「開発者」「私」）が開発・保守しています。プライバシーに関するご質問やご依頼は、こちらまでご連絡ください：mateusmendelson@hotmail.com。

2. 本アプリが収集する情報

さまざまなデバイスでの本アプリの使われ方を把握し、改善するために、本アプリは動作時に小さな利用記録を送信します。この記録には次の情報が含まれる場合があります：

データ取得元目的
生年（おおよその年齢）あなたの Garmin ユーザープロフィール利用者層の把握と本アプリの改善
性別あなたの Garmin ユーザープロフィール利用者層の把握と本アプリの改善
デバイスのモデルデバイスの設定デバイス固有の問題の診断、サポートの優先順位付け
デバイス識別子（Garmin が提供する、インストールごとの一意の識別子）デバイスの設定異なるデバイスの数を数え、重複した記録を除くため
システム言語デバイスの設定対応すべき言語の把握
タイムゾーンの時差 & 利用時刻デバイスの時計利用のタイミングと統計
現在のスポーツ／アクティビティのプロフィール（例：ランニング、サイクリング）Garmin のアクティビティプロフィール本アプリの使われ方の把握
アクティビティを記録中かどうか、および本アプリのバージョン本アプリの状態デバッグとバージョン別統計

生年と性別は、Garmin Connect で設定したプロフィールから読み取られます。設定していない場合、本アプリはこれらを利用できません。

3. ライブトラッキング（Tracker Data Field）

Tracker Data Field には、任意で使えるライブトラッキング機能があります。Track ID を設定してアクティビティを記録すると、データフィールドはそのアクティビティのライブ記録——経過時間、ペース、距離、そして機能が提供する場合は位置情報など、この機能が共有するための値——を時計から開発者が運営するサーバーへ送信します。これにより、apps.mmendelson.com/tracker のトラッキングページが、その Track ID を入力した人に記録を表示できます。

この共有は任意で、あなた自身が開始するものです。Track ID を設定したデータフィールドを実際に使わない限り何も送信されず、開始することが送信への同意となります。あなたの Track ID を知っている人は誰でも共有された記録を見られるため、非公開のリンクとして扱い、信頼できる人にだけ伝えてください。これらの記録は機能の提供に必要な期間だけ保持されます。アクティビティを終了するかデータフィールドを削除すれば、いつでも送信を停止できます。また、保存された記録の削除は「お問い合わせ」に記載のアドレスから依頼できます。

4. 個人が特定されることはありません

本アプリは、あなたの氏名、メールアドレス、電話番号、アカウントのログイン情報を求めたり収集したりすることはなく、上記の情報が Garmin Connect やその他のアカウントにおけるあなたの身元と結び付けられることもありません。デバイス識別子は Garmin が提供する値で、利用記録を数えて重複を除くために、あるデバイスと別のデバイスを区別するだけのものです。あなたの名前ではなく、あなたが誰であるかを突き止めるために使われることもありません。そのため、本アプリが収集する情報だけで、あなたを特定の個人として識別することはできません。唯一の例外は前のセクションで説明した任意のライブトラッキング機能です。そこであなたが自ら共有を選んだ記録には位置情報が含まれる場合があり、あなたの Track ID を知る人なら誰でも見ることができます。それがこの機能の目的です。

5. 情報の利用目的

  • 本アプリがどのデバイス、言語、アクティビティの種類で使われているかを把握するため。
  • 不具合を修正し、改善の優先順位を決め、集計された利用統計を作成するため。

私はあなたの個人情報を販売しません。また、広告や広告プロフィールの作成に使用しません。

6. データの保持 & セキュリティ

利用情報は暗号化された（HTTPS）接続で送信され、本アプリの運用と統計の作成に必要な期間だけ保持され、その後は削除されるか集計された形で保存されます。100% 安全な送信・保存方法は存在しませんが、収集する限られた情報を保護するために合理的な対策を講じています。

7. 子どものプライバシー

本アプリは一般向けのフィットネスツールであり、子どもを対象としたものではありません。現地の法律で定められた年齢に満たない子どもから、故意に個人情報を収集することはありません。子どもがそのような情報を提供したと思われる場合はご連絡ください。削除します。

8. あなたの権利 & 選択

  • 年齢と性別のデータはあなたの Garmin プロフィールに由来します。これらの項目は Garmin Connect でいつでも編集または消去できます。
  • 本アプリはいつでもアンインストールでき、そうすれば動作も利用情報の送信も止まります。ライブトラッキングは、Track ID を設定した Tracker Data Field を実際に使っている間だけ送信します。
  • お住まいの地域によっては、あなたのデバイスにどのような情報が関連付けられているかを無料で問い合わせ、その情報にアクセスし、訂正し、または削除を求める権利がある場合があります。ご依頼があれば、あなたのデバイスまたは Track ID に関連するすべての情報を消去し、以後の処理を停止します。下記のアドレスまでメールでご連絡ください。

9. 本ポリシーの変更

本プライバシーポリシーは随時更新されることがあります。冒頭の「最終更新日」が最新版を示します。重要な変更はこのページに反映されます。

ウェブサイトのアクセス解析と Cookie

このウェブサイトは mmendelson.com ファミリー（mmendelson.com、apps.mmendelson.com、run.mmendelson.com）の一部であり、3つのサイトは1つの Google アナリティクス測定を共有しています。そのため、サイト間を移動する訪問は、無関係な3つの訪問ではなく1つの行動として扱われます。Google アナリティクスは集計された利用状況を記録します。ページビュー、クリックなどのイベントに加え、Google がリクエストから推定する国、地域、都市、言語、ブラウザ、OS、デバイスの種類です。解析用の保存（Cookie）はデフォルトで無効になっており、Cookie バナーで同意した場合にのみ有効になります。同意すると Google シグナルも有効になり、広告のカスタマイズを有効にした Google アカウントにログインしている訪問者について、Google 独自の年齢層・性別・興味関心の推定が追加されます。これらは Google による推定であり、あなたがこのサイトに伝えた情報ではありません。集計としてのみ報告され、数が少なすぎて匿名性を保てない場合、Google はこれらを一切表示しません。拒否した場合、解析は Cookie なしで行われます。集計されたカウントのみで、属性情報も Cookie もありません。3つのサイトいずれのフッターにある「Cookies」リンクからも、いつでも選択を変更できます。ウェブサイトのアクセス解析によって個人を特定できる情報が収集されることはなく、上記の Garmin アプリのデータとは別のものです。

短縮リンク。カードや QR コードに印刷された番号付きの短縮リンク（mmendelson.com/1 など）は、Cookie を使わない別のカウンターでも利用回数を数えています。リンクを開くと、ブラウザがリンクの番号、リンク先、ブラウザの言語設定を、開発者が Google Apps Script で運用している小さなスクリプトに送信し、スクリプトがそれらを時刻とともにスプレッドシートに記録します。Cookie の設定や読み取りは行わず、識別子も付けず、カウンターはあなたの IP アドレスを記録しないため、記録をあなたやあなたの他の訪問と結び付けることはできません。各リンクがどれだけ使われたかを数えるためだけに使われ、アクセス解析の Cookie に同意するかどうかに関係なく同じように動作します。
