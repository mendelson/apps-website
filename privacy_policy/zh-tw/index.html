隱私權政策

M. Mendelson 的 Garmin Connect IQ 應用程式

← 返回應用程式

最後更新：2026年9月13日

本隱私權政策適用於 M. Mendelson 發布的所有 Garmin Connect IQ 應用程式——包括資料欄位與錶面，也包括日後推出的任何應用程式（以下簡稱「本應用程式」）。本政策說明本應用程式收集哪些使用資訊、為何收集，以及你可以做的選擇。

本應用程式從 Garmin Connect IQ 商店安裝，並在你的 Garmin 裝置上執行。你對 Garmin 平台的使用也受 Garmin 自己的隱私權政策 規範，它與本政策各自獨立。

1. 誰是負責人

本應用程式由獨立開發者 M. Mendelson（以下簡稱「開發者」、「我」）開發與維護。如有任何隱私問題或請求，請聯絡：mateusmendelson@hotmail.com。

2. 本應用程式收集的資訊

為了瞭解本應用程式在不同裝置上的使用情形並加以改進，本應用程式在執行時會傳送一筆簡短的使用紀錄。該紀錄可能包括：

資料來源用途
出生年份（即大致年齡）你的 Garmin 使用者個人檔案瞭解使用者族群並改進本應用程式
性別你的 Garmin 使用者個人檔案瞭解使用者族群並改進本應用程式
裝置型號裝置設定診斷特定裝置的問題，決定支援的優先順序
裝置識別碼（由 Garmin 提供、每次安裝唯一的識別碼）裝置設定計算不同裝置的數量並移除重複的紀錄
系統語言裝置設定瞭解需要支援哪些語言
時區差 & 使用時間裝置時鐘使用時間分布與統計
目前的運動/活動設定檔（例如跑步、騎自行車）Garmin 活動設定檔瞭解本應用程式的使用方式
是否正在記錄活動，以及本應用程式的版本應用程式狀態偵錯與版本統計

出生年份與性別讀取自你在 Garmin Connect 中設定的個人檔案。若你沒有設定，本應用程式就無法取得這些資訊。

3. 即時追蹤（Tracker Data Field）

Tracker Data Field 包含一項可選用的即時追蹤功能。當你以 Track ID 完成設定並記錄活動時，該資料欄位會從你的手錶將該活動的即時紀錄——也就是這項功能用來分享的數值，例如經過時間、配速與距離，以及在功能提供時你的位置——傳送到開發者營運的伺服器，讓 apps.mmendelson.com/tracker 上的追蹤頁面可以向輸入該 Track ID 的任何人顯示這些紀錄。

這種分享是選擇性的，並由你主動發起：除非你主動使用設定了 Track ID 的資料欄位，否則不會傳送任何內容，而開始使用即代表你同意傳送。任何知道你 Track ID 的人都能查看分享的紀錄，因此請把它當作私人連結，只告訴你信任的人。這些紀錄只會在提供該功能所需的期間內保存；你可以隨時結束活動或移除資料欄位來停止傳送，也可以透過「聯絡」一節中的地址要求刪除已儲存的紀錄。

4. 無法識別你的個人身分

本應用程式不會要求或收集你的姓名、電子郵件地址、電話號碼或任何帳戶登入資訊，上述資訊也不會與你在 Garmin Connect 或任何其他帳戶中的身分相連結。裝置識別碼是 Garmin 提供的值，僅用來區分不同裝置，以便計算使用紀錄並移除重複——它不是你的姓名，也不會被用來查出你是誰。因此，本應用程式收集的資訊本身無法將你識別為某位具體、具名的人。唯一的例外是上一節所述的選用即時追蹤功能：你主動選擇在其中分享的紀錄可能包含位置資料，任何擁有你 Track ID 的人都能看到——這正是該功能的目的。

5. 資訊的使用方式

  • 瞭解本應用程式在哪些裝置、語言與活動類型中使用。
  • 修正錯誤、決定改進的優先順序，並產生彙總的使用統計。

我不會出售你的個人資訊，也不會將其用於廣告或建立廣告剖析。

6. 資料保存 & 安全

使用資訊透過加密（HTTPS）連線傳送，僅在運作本應用程式與產生統計所需的期間內保存，之後會被刪除或以彙總形式保存。沒有任何傳送或儲存方式是 100% 安全的，但我會採取合理措施保護所收集的有限資訊。

7. 兒童隱私

本應用程式是一般用途的健身工具，並非以兒童為對象。我不會在知情的情況下收集未達當地法律規定年齡之兒童的個人資訊。若你認為有兒童提供了這類資訊，請與我聯絡，我會將其刪除。

8. 你的權利 & 選擇

  • 年齡與性別資料來自你的 Garmin 個人檔案；你可以隨時在 Garmin Connect 中編輯或清除這些欄位。
  • 你可以隨時解除安裝本應用程式，使其停止執行並停止傳送任何使用資訊；即時追蹤只會在你主動使用設定了 Track ID 的 Tracker Data Field 時傳送。
  • 視你所在地區而定，你可能有權免費詢問與你的裝置相關聯的資訊，並存取、更正或要求刪除這些資訊。應你的要求，我會刪除與你的裝置或 Track ID 相關的所有資訊，並停止任何進一步的處理。請寄電子郵件至下方地址。

9. 本政策的變更

我可能會不時更新本隱私權政策。頁面頂端的「最後更新」日期代表最新版本。重大變更將在本頁面上呈現。

網站分析與 Cookie

本網站屬於 mmendelson.com 網站家族（mmendelson.com、apps.mmendelson.com 與 run.mmendelson.com），三個網站共用同一個 Google Analytics 評估，因此在它們之間往來的一次造訪會被視為一段旅程，而不是三次互不相關的造訪。Google Analytics 會記錄彙總的使用情形：網頁瀏覽、點擊及類似事件，以及 Google 從要求中推斷出的國家、地區、城市、語言、瀏覽器、作業系統與裝置類型。分析儲存（Cookie）預設為關閉，只有在你透過 Cookie 橫幅同意後才會啟用。同意後也會啟用 Google 信號，針對已登入且開啟廣告個人化功能的 Google 帳戶的訪客，加入 Google 自行估計的年齡層、性別與興趣——這些是 Google 的估計，絕非你告訴本網站的任何資訊；它們只以彙總形式呈現，而且當人數太少而無法維持匿名時，Google 會完全不顯示這些資料。若你拒絕，分析將在不使用 Cookie 的情況下進行：只有彙總計數，沒有人口統計資料，也沒有 Cookie。你可以隨時透過三個網站任一網站頁尾的「Cookies」連結變更你的選擇。網站分析不會收集任何可識別個人身分的資訊，且與上述的 Garmin 應用程式資料各自獨立。
